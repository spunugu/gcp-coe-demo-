# Optional extras for the connector registry (connectors.py). Install only
# what a given client's sources actually need - none of these are required
# for the base app (sample data, CSV upload, and the core pipeline all work
# without any of this).
#
#   pip install -r requirements-connectors.txt   # everything
#   pip install kafka-python                     # just Kafka
#   pip install sqlalchemy psycopg2-binary       # just Postgres/Cloud SQL
#   pip install sqlalchemy pymysql               # just MySQL
#   pip install requests                         # just REST API
#   pip install gspread google-auth              # just Google Sheets
#   pip install gcsfs                             # just gs:// file paths
#   pip install pyarrow                           # just Parquet files
#   pip install openpyxl                          # just Excel files
#   pip install paramiko                          # just SFTP
#   pip install google-cloud-secret-manager       # Secret Manager credentials
#
# None of these pull in grpc or other native-extension-heavy packages that
# caused the Streamlit Cloud segfault we hit with the GCP client libraries -
# they're either pure Python or use widely-deployed, stable C extensions
# (psycopg2-binary ships a precompiled wheel for virtually every platform).
# google-cloud-secret-manager does depend on grpc like the other GCP client
# libraries - if adding it to requirements.txt on Streamlit Cloud causes
# problems, that's the same known issue; Cloud Run is unaffected.
